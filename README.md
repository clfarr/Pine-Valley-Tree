# Pine Valley Tree Services Website

A professional, responsive website designed for a fictional tree trimming and firewood business. This project showcases a clean, modern design with a focus on user experience and accessibility for small business owners.

## Project Overview

Pine Valley Tree Services is a complete business website featuring service information, company background, and customer contact/order forms. The site is designed to represent a family-owned tree care business with a warm, approachable aesthetic while maintaining professional credibility.

## Features

- **Fully Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Multi-Page Layout** - Home, Services, About, and Contact pages
- **Interactive Forms**
  - Quote request form for tree services
  - Firewood order form with delivery options
  - Client-side form validation
  - Success message feedback
- **Professional Styling** - Custom CSS with a nature-inspired color palette
- **User-Friendly Navigation** - Sticky header with clear navigation menu
- **Service Showcase** - Detailed information about tree trimming, removal, and firewood sales
- **Call-to-Action Sections** - Strategic placement to encourage customer engagement

## Technologies Used

- **HTML5** - Semantic markup for accessibility and SEO
- **CSS3** - Custom styling with CSS Grid and Flexbox
- **JavaScript** - Form handling and interactive elements
- **Responsive Design** - Mobile-first approach with media queries

## Color Scheme

The website uses an earthy, nature-inspired palette:
- Primary Green: #2d5016
- Secondary Green: #4a7c2c
- Accent Brown: #8b4513
- Light backgrounds with strategic use of gradients

## Design Philosophy

This website was designed with small business owners in mind:
- **Trust & Credibility** - Professional appearance with family business warmth
- **Easy Navigation** - Clear menu structure and intuitive user flow
- **Mobile-First** - Recognizing that many users browse on phones
- **Conversion-Focused** - Strategic CTAs and easy-to-use contact forms
- **Accessible** - Semantic HTML and readable typography
